# WILD Ecosystem

Standalone Angular 22 route `/ecosystem` for a living predator-prey evolution experiment.

## Features

- Seeded agent-based predator/prey dynamics, foraging, energy costs, reproduction, mutation and selection.
- Live population counts, evolutionary traits, charts and an event journal, all generated by the simulation.
- Touch and mouse tools for food, currents, local heating/cooling, and organism inspection.
- Immersive Aquarium mode (F) with Zen, Glance and Discover presets and individually toggleable information cards.
- View-only interaction by default in Aquarium mode. Enable interactions explicitly in display settings.
- True browser fullscreen when supported; CSS viewport fallback for platforms like iOS.

## Development

Run from `angular-sandbox/` using `npm install` and `npm start`, then browse to `/ecosystem`.

The engine, renderer and charting functions are framework-independent TypeScript under `sim/`.

## Keyboard

`1`–`5`: tools; `F`: Aquarium; `Space`: pause; `Esc`: leave CSS fullscreen (or browser native fullscreen).
